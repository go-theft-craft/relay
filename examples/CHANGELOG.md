# Changelog — examples

Changes to the `examples/` module, which is where every third-party dependency
lives and where the Minecraft proxy, its recorder and its trace tooling are.

**Nothing here is tagged.** A tag on this repository sets the version a consumer
of `relay` resolves, and the core module has not changed since `0.4.0` — so the
entries below would move that version without changing what it names. The
history is worth keeping; the release is not. Anything that does change the core
belongs in the [root changelog](../CHANGELOG.md) with a tag of its own.

Dates rather than versions, newest first. What the root changelog recorded for
`examples/` up to and including `0.4.3` stays there rather than being copied
across, because those tags exist and rewriting them would be a lie about what
was released.
